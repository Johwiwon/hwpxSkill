# build_report.py 입력 문법

한 줄이 한 문단이다. 줄 첫머리 기호로 종류를 정한다. 빈 줄과 `//` 로 시작하는
줄은 무시한다. 예시는 `examples/sample.txt`.

## 머리 정보 (파일 첫머리, 본문보다 앞)

```
제목: 사내 문서 검색 기능 개선 결과
날짜: ’26. 9. 22          ← 생략 시 오늘 날짜(’YY. M. D)
부서: 정보시스템팀          ← 필수. 사용자에게 받는다(없으면 생성하지 않음)
표머리색: #DFE6F7          ← 생략 시 #DAEEF3
간격: ㅇ=5, 절=8, 절후=5, 항목=1, 표=3, 캡션=1   ← 빈 문단 크기(pt) 바꾸기
```

날짜의 따옴표는 `’`(U+2019)를 쓴다. 생성 결과는 `< ’26. 9. 22  정보시스템팀 >`
(날짜와 부서 사이 공백 2칸)이다.

## 본문 줄

| 입력 | 결과 |
|---|---|
| `□ 개요` | □ 절 (HY헤드라인M 16pt) |
| `ㅇ 문장` (`o `, `○ ` 도 됨) | ` ㅇ 문장` 휴먼명조 15pt |
| `ㅇ (라벨) 문장` | 라벨만 굵게 |
| `- 문장` | `  - 문장` 휴먼명조 15pt (라벨이 있어도 굵게 하지 않음) |
| `* 문장` | 주석. ㅇ 바로 아래면 `  * `, - 아래·표/그림 아래면 `   * ` (함초롬돋움 13pt) |
| `** 문장` | 둘째 주석 |
| `< 제목 >` | 캡션(가운데, 함초롬돋움 13pt 자간 −7). 꺾쇠 안쪽에 공백 |
| `- 이하 여백 -` | 가운데 `- 이하 여백 -` (내용이 끝난 쪽에 빈 공간이 남을 때만 씀) |
| `[붙임] 제목` | 새 쪽 + 붙임 띠(번호는 1부터 자동) |
| 기호 없는 줄 | 앞 ㅇ/-/* 문장에 이어 붙임 |

### 인라인 표시 (본문·표 셀 공통)

| 표시 | 결과 |
|---|---|
| `**굵게**` | 굵게 |
| `{{(1만 건)}}` | 2pt 작게 (괄호 속 보충용) |
| `{빨강:91%}` | 빨간 글씨 (핵심 수치) |
| `{파랑:고친 표현}` | 파란 글씨 (교정 전후 비교) |

겹쳐 쓸 수 있다: `{빨강:**91 (91.0%)**}`

## 표

```
< 표 제목 >                                   ← 선택
[표 글자=11 너비=17,60,23 정렬=c,l,c 폭=전체]    ← 선택, 표 바로 앞 줄
| 구분 | 정확도 | < | 비고 |
| ^ | 기존 | 개선 | ^ |
|---|---|---|---|                              ← 이 줄 위가 머리행(없으면 첫 행)
| 1단계 | 0.62 | 0.71 | 1차 |
|! 2단계 | ^ | 0.91 | 최종 |                     ← |! 로 시작하면 강조 행(#FFF7CC)
| 비고 | 여러 줄은<br>이렇게 | | |
```

- `^` : 위 칸과 병합, `<` : 왼쪽 칸과 병합.
- `<br>` : 셀 안 줄바꿈(새 문단).
- `[그림 경로]` 만 있는 셀: 그 셀 배경에 그림(AS-IS/TO-BE 같은 그림 표).
- `[표 …]` 옵션
  - `글자=11` : 셀 글자 크기(기본 12)
  - `너비=20,30,50` : 열 너비 비율(생략 시 내용 길이로 자동)
  - `정렬=c,l,c` : 열별 정렬(c 가운데, l 왼쪽, r 오른쪽). 머리행은 항상 가운데
  - `폭=전체` : 본문 전체 폭(48180). 붙임 띠 바로 뒤 표는 자동으로 전체 폭

## 그림

```
[그림 img/화면.png]              ← 본문 폭(45360), 높이는 그림 비율대로
[그림 img/화면.png 너비=70]       ← 폭의 70%, 가운데
[그림 img/화면.png 높이=80]       ← 높이 80mm로 고정(그림은 셀에 꽉 채워짐)
```

경로는 입력 파일 기준 상대 경로 또는 절대 경로. png·jpg·gif·bmp.

## 생성기 출력의 「줄 맞춤 보고」

```
맞춤  자간 -9로 2줄→1줄  | - 검색어가 포함된 본문 구절을 …   ← 자동으로 좁힌 문단
확인  2째 줄이 42%만 참 — …  | ㅇ (본문 검색) …               ← 사람이 문장을 다듬을 곳
표셀  자간 -5로 한 줄  | 최신순·정확도순 선택               ← 표 셀을 좁힌 곳
```

'확인' 항목은 문장을 조금 늘리거나 줄여 다시 생성하면 사라진다. 자동 맞춤을
끄려면 `--no-fit`.
