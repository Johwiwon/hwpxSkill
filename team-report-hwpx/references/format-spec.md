# HWPX 구현값 (팀장 최종본 실측)

두 최종본의 `header.xml`·`section0.xml`에서 직접 읽은 값이다. 단위는
HWPUNIT(1mm ≈ 283.46, 1pt = 100)이다.

## 1. 용지·쪽

| 항목 | 값 |
|---|---|
| 용지 | A4 세로 59528 × 84186 (210 × 297mm) |
| 여백 | 왼쪽·오른쪽 5669(20mm), 위 5668(20mm), 아래 4252(15mm) |
| 머리말·꼬리말 | 2834(10mm), 내용 없음 |
| 본문 폭 | 48190 (170mm) |

| 첫 문단 | 구역 정의(secPr) + 단 정의 + 쪽 번호 + 제목 상자가 한 문단에 들어 있음 |

## 2. 글꼴 목록 (fontface, 모든 언어 동일)

굴림체, 함초롬돋움, 함초롬바탕, 휴먼명조, HY헤드라인M
(최종본 B에는 휴먼고딕·한양중고딕이 남아 있으나 본문에서는 쓰지 않는다.)

글자모양(charPr)은 모든 언어(hangul·latin·hanja·japanese·other·symbol·user)에
같은 글꼴·자간·장평을 준다.

| 위치 | 정렬 | 내어쓰기(case 값) | 줄간격 | 줄 나눔(한글) |
|---|---|---|---|---|
| □ | 양쪽 | 0 | 160% | 어절 |

## 10. 미리보기·메타데이터

- `Preview/PrvText.txt` 는 본문 텍스트 앞부분, `Preview/PrvImage.png` 는 첫 쪽
  그림이다. 생성기는 흰 그림을 넣고 한글이 저장할 때 다시 만든다.
- `content.hpf` 의 제목은 보고서 제목으로, 마지막 저장자는 비운다.
- 레이아웃 캐시(`hp:linesegarray`)는 넣지 않는다. 한글이 열 때 다시 계산한다.
  rhwp 같은 미리보기 도구는 캐시가 없으면 빈 문단 간격을 넓게 그리므로
  미리보기의 쪽 수는 실제보다 많게 나온다(최종본에서 캐시만 지워도 같은 현상).
