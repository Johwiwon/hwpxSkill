# 문제와 해결

| 증상 | 원인 | 해결 |
|---|---|---|
| PDF에서 그라데이션 글자 둘레에 가는 사각선 | HTML을 바로 PDF로 인쇄하면 `background-clip:text` 가 선을 남긴다 | 캡처 PNG로 이미지 PDF를 만든다(`pdf.sh`). `inline-block` 등 CSS로는 안 고쳐진다 |
| 인쇄·캡처에서 카드가 잘림 | `transform: translateY(-50%)` 로 세로 가운데 맞춤 | `top: 260px` 처럼 고정 위치를 쓴다 |
| 원문자(①②③) 배지가 원 안의 원으로 보임 | 원 모양 배지 안에 원문자를 넣음 | 배지 안에는 1/2/3 숫자를 쓴다. 문장 속 원문자는 괜찮다 |
| 뜻밖의 색·크기가 적용됨 | 한 글자 클래스(`.a` `.r` `.v` `.m` `.g`)를 구조용 이름으로 씀. 아이콘·칩 색 변형과 겹친다 | 구조용 클래스는 세 글자 이상의 이름을 쓴다(예: `.rw` 대신 `.risk-row`) |
| 장별 스타일이 다른 장을 깨뜨림 | 부품 클래스를 직접 고침 | 장 하나만 바꿀 때는 그 `<section>` 에 이름을 붙이고(`class="slide s-eval"`) `.s-eval .mval {…}` 처럼 범위를 좁혀 맨 아래 deck-specific 절에 적는다 |
| 고정폭 글꼴 상자에서 한글 간격이 벌어짐 | Consolas 등에 한글이 없어 대체 글꼴이 넓게 그려짐 | 상자는 Pretendard로 두고 영문만 `<span class="en">`(고정폭)으로 감싼다 |
| 빌드가 "없는 아이콘"으로 멈춤 | lucide 에 없는 이름 | lucide.dev 에서 이름을 찾아 바꾼다 |
| 아이콘 패키지를 못 찾음 | `~/.cache/dark-seminar-deck` 이 없음 | `new_deck.sh` 를 다시 실행하거나 그 폴더에서 `npm install lucide-static` |
| 셸이 멈춤 | 명령 중간의 `cat`, `npm` 등이 표준입력을 기다림 | 백그라운드·긴 명령 끝에 `</dev/null` 을 붙인다 |
| 캡처가 빈 화면·옛 화면 | 빌드를 안 했거나 글꼴 로딩 전 캡처 | `node _build/build.mjs` 후 캡처. 캡처 스크립트는 `--virtual-time-budget=4000` 으로 글꼴을 기다린다 |
| PDF 쪽수가 슬라이드 수와 다름 | 캡처 폴더에 이전 덱의 `sN.png` 가 남음 | 장 수가 바뀌면 캡처 폴더를 비우고 전체를 다시 캡처한다 |
| WSL에서 크롬이 파일을 못 읽음 | 리눅스 경로를 윈도 크롬에 그대로 넘김 | 스크립트가 `wslpath -w` 로 바꿔 넘긴다. 직접 크롬을 부를 때도 같은 변환을 한다 |
| PPTX 노트에 줄바꿈이 그대로 보임 | pptxgenjs 가 노트 줄바꿈을 한 문단에 넣음 | `pptx.sh` 가 `fixnotes.py` 로 문단을 나눈다 |
