# 글꼴·간격의 HWPX 구현값

## 규칙

> 2026-09-22 팀장 최종본 기준으로 고쳤다. 전체 수치는 team-report-hwpx 스킬의
> `references/format-spec.md` 가 최종 기준이다.

| 위치 | 글꼴 | 예시 |
|---|---|---|
| `□` 절 제목 | **HY헤드라인M** 16pt | `□ 추진 내용` |
| `ㅇ` 항목 · `-` 하위 항목 | **휴먼명조** 15pt | ` ㅇ (목적) …`, `  - …` |
| 표 하단 설명 | **함초롬돋움** 13pt(12pt) | `   * 시험 검색어 100개 기준` |
| 표 안 내용 (머리행·본문셀) | **함초롬돋움** 12pt(조밀 11pt), 머리행 굵게 | |
| 표 위 캡션 | 함초롬돋움 13pt 자간 −7 | `< 점검 내용별 상태 내역 >` |

## 문단 간격

문단 사이는 **3pt**. HWPX 단위로 `vertsize="300"` 인 빈 문단이다.

```
1pt = 100 HWPUNIT  →  3pt = 300
```

한글에서 이미 이렇게 처리된 문서를 편집할 때는 **빈 문단의 크기를 바꾸지
않는다.** 300을 500이나 1000으로 바꾸면 줄 진행량이 달라져 쪽 배분이 통째로
어긋난다. 실제로 빈 문단 크기를 잘못 잡아 본문이 한 쪽 밀린 사례가 있다.

절과 절 사이처럼 더 벌려야 하는 자리는 원본이 쓰던 값(보통 500)을 그대로
따른다. 새로 만들 때의 기준은 아래와 같다.

| 자리 | vertsize |
|---|---|
| 하위 항목 사이, ㅇ → 하위 | 100 |
| ㅇ 항목과 항목 사이 | 300 (최종본 B 500) |
| 절(`□`) 뒤 | 500 |
| 절(`□`) 앞, 작성일 뒤 | 1000 (최종본 B 800) |

## HWPX 적용 방법

글꼴은 두 곳을 함께 고쳐야 한다.

### 1) `Contents/header.xml` 의 fontface 등록

`<hh:fontfaces>` 안에는 언어별 그룹(HANGUL·LATIN·HANJA·JAPANESE·OTHER·
SYMBOL·USER)이 있고, **모든 그룹에 같은 id로 글꼴을 추가해야 한다.**
한 그룹이라도 빠지면 한글이 파일을 열 때 글꼴 참조가 깨진다.

```xml
<hh:font id="7" face="휴먼명조" type="TTF" isEmbedded="0">
  <hh:typeInfo familyType="FCAT_MYUNGJO" weight="0" proportion="0" contrast="0"
    strokeVariation="0" armStyle="0" letterform="0" midline="0" xHeight="0"/>
</hh:font>
```

### 2) `charPr` 의 fontRef 변경

```xml
<hh:charPr id="9" height="1500" ...>
  <hh:fontRef hangul="7" latin="7" hanja="7" japanese="7" other="7" symbol="7" user="7"/>
  ...
</hh:charPr>
```

**`<hp:t>` 를 직접 손대지 않는다.** run 의 `charPrIDRef` 가 가리키는
charPr 하나만 고치면 그 스타일을 쓰는 모든 문단에 한 번에 적용된다.

`scripts/apply_fonts.py` 가 이 두 단계를 자동으로 처리한다.

## 주의

- **글꼴 이름은 시스템에 설치된 것과 정확히 일치해야 한다.** 「휴먼명조」와
  「HY견명조」는 다른 글꼴이다. 없는 글꼴을 지정하면 한글이 임의로 대체한다.
- 같은 크기라도 자리마다 charPr 이 나뉘어 있는 경우가 많다. 한글에서 사람이
  편집하면 charPr 이 계속 분화되기 때문이다. **id 하나만 고치고 끝났다고
  보지 말고, 적용 후 실제 문단들을 확인한다.**

## 줄 채움 — 어중간한 줄을 남기지 않는다

한 항목이 **두 줄로 넘어가면서 둘째 줄이 조금밖에 안 차는 상태**를 피한다.
남는 여백이 눈에 띄고 문서가 성글어 보인다. 두 가지 방법이 있다.

### 1) 한 줄로 줄일 수 있으면 자간을 좁힌다

둘째 줄에 몇 글자만 넘어간 경우다. 한글에서 그 문단을 선택하고
**`Alt`+`Shift`+`N`** 을 눌러 자간을 좁히면 한 줄에 들어간다.
반대로 넓히는 것은 `Alt`+`Shift`+`W` 다.

HWPX 에서는 charPr 의 자간 속성에 해당한다.

```xml
<hh:charPr id="9" height="1500" ... >
  <hh:spacing hangul="-5" latin="-5" hanja="-5" japanese="-5"
              other="-5" symbol="-5" user="-5"/>
</hh:charPr>
```

값은 백분율이고 음수가 좁힘이다. `Alt`+`Shift`+`N` 한 번이 대략 `-1`.
**다만 자간을 건드리면 그 charPr 을 쓰는 모든 문단이 함께 좁아진다.**
한 문단만 좁히려면 그 문단 전용 charPr 을 복제해서 쓰거나, 한글에서 직접
누르는 편이 안전하다. 자동화보다 사람 손이 나은 자리다.

### 2) 두 줄이어야 하면 둘째 줄을 채운다

내용상 한 줄로 못 줄이면, **둘째 줄이 중간 기점을 넘도록 문장을 보강한다.**
근거·수치·조건을 덧붙이면 자연스럽게 채워진다.

```
전:  ㅇ 사내 검색은 범용 문서 검색용으로 구축되어 회의록의 안건 검색에는
     특화가 미흡                                    ← 둘째 줄 16%

후:  ㅇ 사내 검색은 범용 문서 검색용으로 구축되어 회의록처럼 안건이 여러 개
     섞인 문서의 안건별 검색에는 특화가 미흡          ← 둘째 줄 50% 이상
```

**빈 자리를 메우려고 없는 말을 지어내면 안 된다.** 채울 내용이 없으면
1)번으로 한 줄에 넣는 편이 낫다.

### 쓰기 전에 미리 재기

이미 만든 문서는 `check_report.py` 가 실제 줄바꿈 위치를 읽어 채움률을 낸다.
**문장을 새로 지을 때는** 아직 줄바꿈이 없으므로 글자 폭으로 어림한다.

| 글자 크기 | 한 줄에 들어가는 폭 |
|---|---|
| 16pt (`□`) | 70 |
| 15pt (`ㅇ`, `-`) | **74** |
| 13pt (`*`) | **78** |

폭은 **동아시아 문자 2, 그 외 1**로 센다. 본문 폭 48188 기준이며, 한글이
실제로 잡은 줄바꿈 위치를 역산해 얻은 값이다.

```python
def W(s):
    return sum(2 if unicodedata.east_asian_width(c) in 'WF' else 1 for c in s)

w = W(문장); 줄수 = -(-w // 74); 마지막채움 = (w - (줄수-1)*74) / 74
```

목표는 **마지막 줄 채움률 50~90%** 다. 90%를 넘으면 실제로는 한 줄 더
넘어갈 수 있으니 한 문장을 덜어낸다.

### 점검

`scripts/check_report.py` 가 문단별 마지막 줄 채움률을 계산해 알려준다.

| 채움률 | 판정 | 대응 |
|---|---|---|
| 15% 미만 | 한 줄로 줄일 여지 | `Alt`+`Shift`+`N` 로 자간 좁힘 |
| 15~50% | 채움 부족 | 문장을 보강해 둘째 줄을 채움 |
| 50% 이상 | 정상 | — |
